# Discord サーバー開設ガイド

『コミックさいたま』の Discord サーバーを作り、公式サイトに載せるまでの手順です（issue #12）。
Discord の画面の名前や配置は変わることがあるので、見つからないときは似た名前の項目を探してください。

## 0. 目的と方針

- **目的**: 募集開始・日程決定などのお知らせを確実に届けること。あわせて、参加者・スタッフ同士の交流や、準備会への質問の窓口にする
- **方針**: お知らせは運営だけが書き込めるチャンネルに集約し、雑談や質問とは分ける
- サイトの「最新情報を受け取る」欄・フッターからこのサーバーに案内される

## 1. サーバーを作る

1. Discord 左側の「＋（サーバーを追加）」→「オリジナルの作成」
2. 「クラブやコミュニティのため」を選ぶ
3. サーバー名: `コミックさいたま`、アイコン: ロゴ画像（リポジトリの `public/assets/images/logo.png`）
4. 作成したら、運営メンバーを招待しておく（このあとロールを付ける）

## 2. コミュニティ機能を有効にする

「アナウンスチャンネル」（他のサーバーからフォローできるお知らせ専用チャンネル）を使うために必要です。

1. サーバー名 →「サーバー設定」→「コミュニティを有効にする」
2. 案内に沿って次を設定する
   - 認証レベル: メール認証済み以上（下の「5. 安全対策」で「中」に上げる）
   - 不適切なメディアのスキャン: すべてのメンバー
   - ルールチャンネル: `#ルール`
   - コミュニティ更新チャンネル: `#運営連絡`（運営だけが見えるチャンネル）

## 3. チャンネル構成

| カテゴリ | チャンネル | 種類 | 書き込める人 | 用途 |
|---|---|---|---|---|
| 📢 インフォメーション | `#ルール` | テキスト | 運営 | サーバーのルール（下の文案を貼る） |
| | `#お知らせ` | **アナウンス** | 運営 | 募集開始・日程・当日情報など。サイトのお知らせ・X と同じ内容を投稿 |
| 💬 交流 | `#雑談` | テキスト | 全員 | 自由な交流 |
| | `#作品紹介` | テキスト | 全員 | 自分の作品・サークルの紹介（宣伝はここだけ） |
| ❓ サポート | `#質問・問い合わせ` | テキスト | 全員 | 準備会への質問。個人情報を含む相談はメールへ誘導 |
| 🛠 運営（非公開） | `#運営連絡` | テキスト | 運営 | 運営内の連絡、Discord からの通知 |
| | `#web更新` | テキスト | 運営 | サイト更新の相談（GitHub の issue へのリンクなど） |

サークル参加者・スタッフ向けのチャンネル（例: `#サークル連絡`、`#スタッフ連絡`）は、募集が始まってから追加します。

## 4. ロールと権限

| ロール | 付ける人 | 主な権限 |
|---|---|---|
| `運営` | 準備会の中心メンバー | 管理者。`#お知らせ`・`#ルール` への投稿、メッセージ管理、メンバーのタイムアウト |
| `スタッフ` | 運営スタッフ | スタッフ用チャンネルの閲覧・投稿 |
| `サークル` | サークル参加が決まった人（募集開始後） | サークル用チャンネルの閲覧・投稿 |
| `@everyone` | 全員 | 交流・サポートのチャンネルの閲覧・投稿 |

設定のポイント:

- `#お知らせ` と `#ルール` は、チャンネルの権限で `@everyone` の「メッセージを送信」をオフ、`運営` をオンにする
- 運営カテゴリは、`@everyone` の「チャンネルを見る」をオフ、`運営` をオンにする
- 管理者権限を持つ人は最小限にする（2〜3人）

## 5. 安全対策

「サーバー設定」→「安全設定（またはモデレーション）」で設定します。

- **認証レベル: 中**（Discord 登録から5分以上経ったアカウントのみ発言可）
- **不適切なメディアのフィルター: すべてのメンバー**
- **AutoMod**: 「スパムの疑いがあるコンテンツをブロック」「よく使われる不適切な言葉をブロック」をオン。通知先は `#運営連絡`
- 荒らしがあったときは、メッセージ削除 → タイムアウトまたはキックで対応し、`#運営連絡` に記録を残す

## 6. ルールの文案（`#ルール` に貼る）

```text
コミックさいたま Discord サーバーのルール

このサーバーは、むつめ祭同人即売会『コミックさいたま』に関心のある方のための場所です。気持ちよく過ごせるよう、次のルールを守ってください。

1. 互いを尊重してください。誹謗中傷・差別的な発言・ハラスメントは禁止です。
2. 成人向けの内容や、公序良俗に反する投稿は禁止です。
3. スパム、同じ内容の連投、無関係な宣伝は禁止です。作品やサークルの紹介は #作品紹介 でどうぞ。
4. 他人の個人情報（本名・学籍番号・連絡先など）を投稿しないでください。
5. 著作権・肖像権を侵害する投稿は禁止です。
6. 準備会への質問は #質問・問い合わせ へ。個人情報を含むご相談は comic.saitadai@gmail.com までメールでお願いします。
7. ルールに反する投稿があった場合、運営の判断で投稿の削除や、サーバーからの退出をお願いすることがあります。

最新情報は #お知らせ でお届けします。
```

## 7. 招待リンクを作る

**サイトに載せるリンクは、期限切れにならない設定で作ってください。** 既定（7日で失効）のままだと、サイトのリンクが使えなくなります。

1. `#お知らせ` チャンネルの横の「招待を作成」（人型＋のアイコン）
2. 「招待リンクを編集」
3. **有効期限: 期限なし**、**最大使用回数: 無制限** にして「新しいリンクを生成」
4. 表示された `https://discord.gg/xxxxxxx` をコピー

## 8. サイトに反映する

1. `src/data/site.ts` の `discord.inviteUrl` に、7でコピーしたURLを入れる PR を出す（または issue #12 にURLを書けば、Web担当が反映）
2. マージ後、次の3か所に Discord が表示されることを確認する
   - トップ・参加詳細の「最新情報を受け取る」欄
   - 全ページのフッター
   - トップの告知帯の文言（「Discord・X・メーリングリストで〜」）

## 9. 運用のコツ

- お知らせは **サイトのお知らせ → Discord `#お知らせ` → X** の順に、同じ内容を出す（サイトを一次情報にする）
- `#お知らせ` は「アナウンスを公開」すると、フォローしている他サーバーにも届く
- 個人情報のやりとりは Discord 上で行わず、メールや Google フォームを使う
